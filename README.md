# Uzbek-ASR

The data for this project uses the Uzbek Speech Corpus dataset which is an open-source speech corpus containing around 105 hours of transcribed audio recordings spoken by 958 different speakers from different regions and ages. To the best of our knowledge, USC is the first open-source Uzbek speech corpus available for both academic and commercial use under the Creative Commons   Attribution 4.0 International License.

https://huggingface.co/datasets/issai/Uzbek_Speech_Corpus
